About DocuFormat

DocuFormat exists for the moment you paste something messy and just need it to be clean, valid and understandable.

Coming soon ↗

The idea

Developers constantly handle structured text: API responses, config files, exports, queries, and commands copied from somewhere else. Formatters handle the easy case, when the input is already valid. DocuFormat is built for the other case too.

Its guiding rule: use deterministic tools when possible, and use AI when needed. Parsers are reliable and fast, so they do the routine work. AI is kept for tasks that call for reasoning: repairing malformed input and explaining it.

What it covers

  • JSON formatter: Pretty-print, minify, validate and repair JSON.
  • YAML formatter: Clean up YAML and identify indentation and syntax problems.
  • XML formatter: Pretty-print XML and identify malformed tags and nesting.
  • CSV formatter: Inspect, format and validate CSV with structured table previews.
  • SQL formatter: Format SQL queries and use AI to explain or help repair problematic SQL.
  • cURL formatter: Turn difficult-to-read cURL commands into understandable API requests.
  • Shell formatter: Convert long shell commands between readable multi-line and terminal-friendly single-line formats.

How it is meant to be used

Open it, paste, and go. There is no account to create before trying the formatter. If you want to know what happens to your data, the privacy page is specific about it, and the features page lists what DocuFormat does and does not do.

Paste it. Fix it. Move on.

DocuFormat is not open to the public yet.
